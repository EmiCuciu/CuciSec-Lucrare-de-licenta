================================================================
ARHITECTURA RETEA
================================================================

Topologie:

  [Attacker 10.0.5.5]          [CuciSec]              [Client 10.0.3.5]
   NAT Network WAN    <->   10.0.5.10 | 10.0.3.10  <->   NAT Network LAN
   NAT simplu                enp0s8   |   enp0s9         NAT simplu
   (internet)              NAT simplu enp0s3               (internet)
                           (internet/SSH PyCharm)

Tot traficul Attacker -> Client trece OBLIGATORIU prin CuciSec.
CuciSec intercepteaza fiecare pachet prin NFQUEUE inainte de a-l trimite mai departe.

T2 — FLOOD ENGINE
================================================================

Praguri userspace:
  TCP  > 200 pachete / 12 secunde -> DROP + BAN
  UDP  > 250 pachete / 12 secunde -> DROP + BAN
  ICMP > 30  pachete / 12 secunde -> DROP + BAN

T2.1 — TCP Flood
  (Attacker) hping3 -S -p 80 --flood 10.0.3.5
  # Asteptat: DROP + BAN dupa depasirea pragului TCP
  # Log: FLOOD_BAN_DROP: TCP flood detected
  (Attacker) curl http://10.0.5.10:8000/api/blacklist/
  # Unban:
  (Attacker) curl -X DELETE http://10.0.5.10:8000/api/blacklist/10.0.5.5

T2.2 — UDP Flood
  (Attacker) hping3 --udp -p 53 --flood 10.0.3.5
  # Asteptat: DROP + BAN dupa depasirea pragului UDP
  # Unban dupa test

T2.3 — ICMP Flood
  (Attacker) hping3 --icmp --flood 10.0.3.5
  # Asteptat: DROP + BAN dupa ~30 pachete ICMP in 12s
  # Unban dupa test

T5 — RULE ENGINE (reguli statice L3/L4)
================================================================

T5.1 — Adauga regula DROP pe IP atacator
  (Attacker) curl -X POST http://10.0.5.10:8000/api/rules/ \
    -H "Content-Type: application/json" \
    -d '{"ip_src":"10.0.5.5","protocol":"TCP","port":80,"action":"DROP","description":"Block attacker HTTP"}'

  (Attacker) curl http://10.0.3.5
  # Asteptat: DROP — Apache nu mai primeste request-ul
  # Log: RULE_ENGINE_DROP

T5.2 — Disable regula (hot-reload fara restart)
  # Gaseste ID-ul regulii:
  (Attacker) curl http://10.0.5.10:8000/api/rules/

  # Disable (inlocuieste {id} cu ID-ul real):
  (Attacker) curl -X PATCH http://10.0.5.10:8000/api/rules/{id} \
    -H "Content-Type: application/json" \
    -d '{"enabled": false}'

  (Attacker) curl http://10.0.3.5
  # Asteptat: din nou ACCEPT — hot-reload fara restart interceptor

T5.3 — Sterge regula
  (Attacker) curl -X DELETE http://10.0.5.10:8000/api/rules/{id}

T5.4 — Ban manual IP din API
  (Attacker) curl -X POST http://10.0.5.10:8000/api/blacklist/ \
    -H "Content-Type: application/json" \
    -d '{"ip":"10.0.5.5","reason":"Test ban manual"}'

  (Attacker) ping 10.0.3.5
  # Asteptat: DROP — IP in blacklist kernel nftables

  # Unban:
  (Attacker) curl -X DELETE http://10.0.5.10:8000/api/blacklist/10.0.5.5
